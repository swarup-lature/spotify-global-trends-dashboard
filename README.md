# Spotify Global Trends Dashboard 🎵📊

An interactive business intelligence and data analysis project built in Microsoft Excel to uncover global music streaming dynamics, chart performances, and listener engagement patterns across top artists and genres.

---

## 📌 Project Overview
The **Spotify Global Trends Dashboard** processes 178 track records across multiple international markets and music categories. By leveraging advanced Excel tools—such as Pivot Tables, customized slicers, and calculated metrics—this project transforms raw audio data into clear, actionable insights regarding international listening habits.

---

## 🛠️ Tools & Techniques Used
* **Microsoft Excel:** Data organization, cleaning, and structured tabular modeling.
* **Pivot Tables & Aggregations:** Summarizing massive datasets across dimensions like artists, genres, and countries.
* **Interactive Slicers:** Dynamic filtering enabling multi-parameter user exploration.
* **Data Visualization:** Structured layout designed for executive-level reporting (also exported as a formal `Spotify_Dashboard.pdf` summary).

---

## 📂 Repository Contents
* `Spotify_Dashboard.xlsx`: The primary Excel workbook containing raw track datasets, summary tables, and the interactive dashboard interface.
* `Spotify_Dashboard.pdf`: A formal PDF export displaying the final visual layout and key performance indicators.

---

## 📈 Key Insights & Dataset Highlights
* **Total Records Analyzed:** 178 global track entries.
* **Top Performing Artists:** Dominated by powerhouse acts such as **BTS**, **Bad Bunny**, and **Bruno Mars**.
* **Leading Genres:** **Pop** and **K-Pop** capture the highest aggregate stream volumes globally.
* **Dynamic Breakdown:** Features granular categorization across track positions, viral scores, streaming momentum (`stream_change`), and audience longevity categories (*New vs. Evergreen*).

---

## 🚀 How to View
1. Download or clone the repository.
2. Open `Spotify_Dashboard.xlsx` in Microsoft Excel to interact with the Pivot Tables and filters.
3. Review `Spotify_Dashboard.pdf` for a quick executive summary of the visual layout.
